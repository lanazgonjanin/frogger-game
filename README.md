# Frogger game

The following are instructions for compiling and running the Frogger game.

## How to run

1. Open the `frogger.c` file in VS Code (or a preferred text editor or IDE)
2. In the terminal, navigate to the directory where `frogger.c` is located
3. Compile the program by running:
   ```bash
   gcc -o FroggerGame frogger.c
   ```
4. Run the game by running:
    ```bash
   ./FroggerGame
    ```
5. Play the game, good luck!
6. If you lose, start again by re-running:
    ```bash
   ./FroggerGame
    ```
